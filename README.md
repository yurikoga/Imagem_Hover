# Image Hover Animation using HTML & CSS | Z-Index Transition

Um projeto simples de **animação em imagens no hover** usando HTML e CSS.

## ✨ Sobre

Este projeto demonstra como criar um **efeito de hover em imagens utilizando z-index e transições**, deixando o layout mais interativo.

## 🛠️ Tecnologias

- HTML
- CSS (transition, z-index)

## 🎯 Funcionalidades

- Efeito hover em imagens
- Uso de z-index para sobreposição
- Animação suave

## 🚀 Como usar

1. Baixe ou clone o repositório  
2. Abra o arquivo `index.html` no navegador
